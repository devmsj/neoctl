## 修复

1. OpenAI Responses/Chat、Claude 未完成 EOF 归类为可重试断流。已有正文、思考或工具参数不再阻止原请求重试。
2. 重试层保留流式预览，最终消息、工具调用与非临时用量在本次响应有效结束后提交。失败尝试不进入工具执行或正式历史；重试清除 query、压缩摘要和 UI 的尝试内临时状态。
3. Responses `response.failed` 显式报错；业务 completed 后直接结束，不被连接收尾错误覆盖。Chat 保留尾部 usage，只有完成后的传输收尾失败可忽略，参数解析错误和明确上游错误仍报错。
4. 输出截断不会误报成功；保留现有一次输出上限恢复。Chat 续写保留完整历史，不使用 Responses 响应链。Claude pause_turn 允许一次续跑，持续暂停明确中断，不无限循环。
5. 工具 `tool.result.available` 发布前逐项写入引擎历史/会话日志，随后消息通知不重复落盘；下一轮模型输入与持久化历史采用一致的结算顺序。
6. SSE 结束/错误/超时释放 reader，避免重试留下旧读取资源。
