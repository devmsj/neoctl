# 逐行工具历史与观察窗口

入口：模型配置的“历史展示”。默认保留原折叠视图，逐行视图选择保存在当前浏览器，不修改会话模型消息。

## 生命周期与增量

- Core 消费模型提供者的工具调用生命周期。`tool_call.started` 立即建立行，即使参数尚为空。
- `ToolInputStream` 仅解码工具参数 JSON 协议。`tool_call.input` / `line.activity.input` 发送结构化 `set` / `append` 路径操作，页面不解析助手文字或日志，不每 token 发送整份参数快照。
- 未完成的字符串和嵌套计划可持续显示。参数展示上限 80k 字符、20 层；超过范围只停止追加预览，不改变真正执行的完整参数。
- `tool_call.ready` 表示参数完整、已排队；`tool.started` 原来是批量入队通知，不将它当成实际执行。调度的 `timing.updated(running)` 才转为执行。
- 同一 callId 从生成、排队、执行到结果始终复用同一行；中断收尾为 interrupted。生成草稿不是已经落盘的内容。
- 动作只来自生命周期；内容只来自已解码参数和真实工具结果。读取完成文本可以固定 1800ms 滚动，但不伪造执行时长或成功状态。

## 快照的职责

快照仅作首次加载、结构性同步和重连恢复，不作逐 token 动画来源。相同投影在同步时保留引用，不抢观察焦点，不重播入场。历史从已有 tool_use / tool_result 重建，不另存每一个 token。

结果 observation 是有界结构化投影（总文本40k、单字段16k、数组80项、12层）；完整内容仍走已有详情或终端输出接口。本轮没有新增敏感字段过滤，既有脱敏和子任务来源授权保持。

图标后优先直接显示模型填写的非空purpose，其次为非空description，不添加工具名前缀或兜底参数；两者均未提供或仅空白时使用已核对schema的完整自然语言模板，不用装饰点号，模板保留命名参数方便i18n。并未增加假目的参数。

## 同次模型调用的工具连线

- 同一次模型调用的工具连接，不按实际并发分组；第二个工具出现后开始播放，单个工具不画线。
- 工具行只有 `connectPreviousTool` 展示标记，不新增 turn ID，不写入模型请求。模型调用边界只划分组，不负责结束动画。
- 每组首次出现固定播放 2 秒，再用 240ms 淡出。新模型调用、回复、完成及暂停均不提前结束，也不重置计时。过期后不因参数更新或历史滚动重播；首次加载的历史不播放。
- 连线绝对定位，保持图标及正文对齐。pin 内容更新、切换和收起在绘制前同步虚拟行尺寸，避免测量延迟造成瞬时断线。

## 唯一观察窗口

- 自动主窗通过Teleport随最末工具行移动，不因新增行重置读取动效或终端reader。锚点使用自然文档流；实测高度仅用于虚拟列表初始估算。
- 主窗不可操作、不参与键盘焦点，内容上下渐隐呈草稿感。入场、出场用240ms淡入淡出及高度收拢，遵循reduced-motion。
- 短内容按实际高度收缩，普通长内容最高190px、富内容最高360px，窄屏上限分别170px、300px；不设最小高度，不保留多余底部空白。展示时忽略尾部空白，不改原始内容。
- 自动跟随最近有效内容更新，不排队补播。不同来源自动切换至少间隔800ms；同来源内容立即更新。点击钉住不改变自动目标。
- 点击工具行后，在该行正下方显示一个虚线框pin窗，再次点击解除；切换工具时移动pin窗。pin窗与主窗使用相同内容及高度上限。pin窗允许鼠标、触摸和键盘滚动，手动滚动后同目标的新输出不抢回位置，换目标恢复自动展示。
- 同一调用被钉住且正在主窗观察时，主窗淡出，避免重复；两者目标不同则同时显示。图钉保留顿挫动作。
- 助手正式文字开始输出后主窗淡出，pin窗保留；空助手占位、思考和系统信息不触发。后续新工具调用再开启主窗，历史工具的迟到更新不会盖过回复阶段。
- 图片和插件交付物留在行下，不参与完成后的自动观察竞争。读取图片只显示真实缩略图。
- 暂停或连接中断时冻结动效并停止终端轮询；恢复沿用现有内容和byte cursor。
- 终端启动事件提供session_id，静默进程不必等首段输出或工具返回才关联。SSE仅发输出失效通知，reader立即按独立字节游标读取末段，1s轮询兜底。进程running即持续运行，不把工具调用success当进程结束。
- 子任务关联必须taskId和runGeneration吻合，最终获准报告优先于较旧的可见进展；不串到后续恢复轮次。

## 布局与兼容

图片从开始就预留画幅及操作栏，插件按已知类型预留，未知尺寸用StableSurface测量并平滑调整。详情内容只出现一次，外部已有下载则内部不重复。新逐行图片详情直接读取结构化metadata，旧折叠视图保留历史兼容解析。

读取图片的隐藏附加消息只投影image blocks，带observationOnly标记；原隐藏文字不展示，原折叠视图不新增这些行。

图标为已确认的平面SVG，颜色使用现有日夜主题变量。动态图标表达工具本体动作。思考使用同系列16px线描脑形，复用ToolActivityIcon，内部左右线条错峰亮起；只在真实live阶段运动，暂停或断线冻结，完成静止。移除旧彩色绕转标记和装饰下划线，用户与模型正文仍无角色图标。遵循prefers-reduced-motion，无需图像模型参与运行。

精修样式集中在 `rows-history.css`，仅对逐行视图的对话区域生效。深色使用石墨底#111418、正文#d7dce3、工具说明#9aa4b2、灰玫瑰图标#bb8ea6；日间提供独立浅色变量，不修改侧栏和原折叠主题。

用户消息以浅底细边框消息带区分，模型回复直接呈现正文，两者均不显示角色标题、图标或预留图标列，保留aria-label。用户文字含12px内边距与1px边框，以13px为正文基准；模型正文左缘与工具图标左缘对齐，工具说明及观察内容再缩进22px。窄屏沿用相同基准。工具保持原SVG形状与动作，失败时图标也保留原色，不置红；执行失败仍以真实生命周期和结果表达。普通文字不加粗，助手正文15px/24px。原折叠视图角色标题和标记不变。

工具行高26px、文字12px、图文间距6px。思考行同为26px，不保留旧容器上下留白；空思考内容不创建正文容器。思考正文使用辅助文字色、11px/18px，与工具说明左缘对齐，移除彩色竖线、扫光和文字呼吸，动态仅保留在图标。虚拟列表从初次估算起为折叠思考保留26px，重新进入视野不重播整块位移动画；思考与工具共用主窗、pin选择器与虚拟锚点，不再使用独立details展开；点击钉住，再点取消，pin可手动滚动，同目标主窗隐藏，异目标共存，正式回复只关闭主窗。思考Markdown标题和强调统一为观察文字的字号、字重和颜色，不再继承正文高对比标题样式。观察文本11px/18px，计划文字12px/18px、单行含内边距24px、状态图标13px；目录与任务条目22px高。观察命令图标、嵌套缩进、检索间距及读取缩略图同步缩小，助手正文与行下交付图片不随之缩放。

## 终端原生颜色与模型阶段

- 终端stdout/stderr分别增量解码真实ANSI SGR，保留跨分块样式；16色按日夜终端色板显示，256色与RGB保留指定颜色。不按单词猜颜色、不强制PTY或FORCE_COLOR。OSC等非样式控制不执行，内容由Vue转义。
- 末段读取若缺少先前颜色序列，使用默认色直到收到有效新序列，不猜丢失状态；此处是输出查看器，不是完整终端光标仿真器。
- 回复阶段来自协议生命周期：实际文本增量为“生成回复”；提供者确认文本段结束后清除输出状态，仍在模型请求中显示“调用模型”；工具参数生成显示“准备工具”。新请求和完整助手消息也清除旧文本状态，不扫描历史正文、不用token间隔猜阶段。
- 验证：`node web/tests/terminal-ansi-browser.test.mjs`及Core模型映射、query、Web状态回归。

## 外围界面主题与浅色可读性

- `chrome-theme.css`仅向侧栏、输入区、右侧面板、配置页面与传送弹窗提供主题变量，不覆盖对话区域布局或旧折叠视图。
- 浅色以白底、深色正文、灰玫瑰选中态和1px边框建立层级，不使用大片灰底或偏移阴影；夜间维持独立深色变量。
- 观察窗终端输出不得继承后台任务黑底预览的固定浅色前景；stdout与stderr无显式ANSI颜色时均跟随观察窗文字色，不将整个stderr染红。pin窗内容不再降低透明度；主窗仅保留边缘渐隐与原有出入场。
- 浏览器验证：`node web/tests/chrome-theme-browser.test.mjs`，覆盖日夜、配置下拉、建议删除确认、会话搜索、目录弹窗、窄屏导航与浅色终端输出。
