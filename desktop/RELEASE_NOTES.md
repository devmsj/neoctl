# Neo Desktop 0.1.38

Includes Web 0.1.35 and Core 0.2.57.

- Redesign reasoning effort as one horizontal energy bar with theme-aware fill, aligned tier ticks, a softly glowing handle and a moving highlight that accelerates with higher effort.
- Preview other tiers on hover without changing the selected value. Preserve drag, keyboard, custom-tier, empty and single-tier behavior, narrow-screen layout and reduced-motion support.
- Keep the change scoped to the reasoning control and its browser regression test. Model settings, persistence, provider requests and Core remain unchanged.

Windows x64 installer, SHA-256 checksum, source commit, and payload/version manifests are attached to this release.
