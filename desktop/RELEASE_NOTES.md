# Neo Desktop 0.1.42

Includes Web 0.1.57 and Core 0.2.77.

- Fix launcher tooltip contrast with a dark surface and readable light text matching the launcher.
- Remove redundant launcher tooltips from text buttons, including Stop Backend and Update Web / Core; retain useful hints for icon-only controls and warnings.
- Include the latest model-speed indicator with first-output timing, compact concurrent-request bars and per-request hover details.
- Include the latest workspace rendering isolation and subagent interaction improvements from Web and Core.

The launcher fixes are bundled into the desktop application. Updating Web / Core alone does not update the launcher; install this desktop release to receive them.

Windows x64 installer, SHA-256 checksum, source commit, and payload/version manifests are attached to this release.
